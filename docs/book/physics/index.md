title: Physics
summary: "The quantities the library computes: their definitions, the formulas used for them, and where those formulas come from."
---

This part defines the quantities that parkin computes and derives the formulas
it uses for them. It is written for a reader who wants to know exactly what a
number returned by the library means: which definition it follows, which
conventions apply where that definition ends, and how the formula was brought
into a form that keeps its precision in floating-point arithmetic.
